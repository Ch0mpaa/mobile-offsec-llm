## Key Findings

1. **Performance is solid** — 17 tok/s generation on a phone CPU is usable for field work
2. **Thinking mode is the bottleneck** — Qwen3's reasoning consumes 80%+ of token budget before producing output. Need either:
   - Larger token budget (500-1000 per test)
   - Abliterated model that skips reasoning preamble
   - Non-thinking variant (Qwen3-4B-Base with chat template override)
3. **One refusal out of 8** — payload_encode refused (PowerShell cradle). Abliteration needed for full offsec capability.
4. **Prefill speed impressive** — 26-30 tok/s prompt processing means context loading is fast even for longer prompts
